# 🚨 Scareware Simulation - Educational Tool

A safe, educational website that simulates scareware techniques to help users understand and avoid real threats.

## 🎯 Purpose

This website demonstrates common scareware and browser hijacking techniques in a controlled, educational environment. Users can safely experience what these threats look like while learning how to identify and escape from real situations.

## ⚠️ Important Safety Notice

**This is a 100% safe educational simulation.** 
- No actual system changes are made
- No downloads or installations occur
- All threats shown are completely fake
- Clear "SIMULATION MODE" indicators throughout
- Easy exit options always available

## 🚀 Getting Started

### Prerequisites
- Node.js (version 14 or higher)
- npm or yarn

### Installation

1. Clone or download this repository
2. Navigate to the project directory
3. Install dependencies:
   ```bash
   npm install
   ```

### Running the Application

Start the development server:
```bash
npm start
```

The application will open in your browser at `http://localhost:3000`

## 🎮 How to Use

### Starting the Simulation
1. Read the safety information on the home page
2. Click "Start Simulation" to begin
3. Follow the guided experience through different scareware techniques
4. Use the control panel to manually advance phases if desired

### Simulation Phases

1. **Fake Popup Alerts** - Demonstrates scareware pop-ups with persistence
2. **Fake System Scan** - Shows simulated virus scans with urgency tactics
3. **Fullscreen Overlay** - Simulates browser hijacking with escape prevention
4. **Persistence Demo** - Real scareware techniques: multiple overlays, blocked escape methods
5. **Escape Guide** - Provides real escape procedures and safety information

### Educational Features

- **Learn More** buttons throughout provide detailed information
- **Control Panel** allows manual phase progression
- **Educational overlays** explain what's happening
- **Real escape procedures** for actual scareware encounters

## 🚨 Real Scareware vs Simulation

### Real Scareware Characteristics
- Creates actual system changes
- Demands real payments
- Difficult to close or escape
- May steal personal information
- Can damage your computer

### This Simulation
- No system changes
- No real payments
- Easy to exit anytime

- Completely safe
